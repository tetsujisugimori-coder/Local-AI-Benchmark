# CLI Coding Agent比較研究

## 目的と範囲

この研究領域では、Copilot CLIとCodex CLIによるソフトウェア修正の能力を、同一の課題・基準ソース・評価条件で比較する。既存のOllamaベンチマークとは独立しており、アプリの実行処理、Ollama接続、既存採点ロジックには影響しない。

この第0段階では研究手順と記録形式だけを整備する。エージェントに課題を解かせたり、修正を実施・採点したりはしない。

## 実験を行う場合

1. 課題、対象リポジトリと基準SHA、共通指示、評価条件を固定し、開始前に記録テンプレートを埋める。
2. 同一の基準ソースからエージェントごとの独立した作業ディレクトリを用意する。エージェント間で作業ディレクトリや成果物を共有しない。
3. 正解資料と隠しテストをエージェントおよび実験者の作業範囲から隔離する。Git除外はアクセス制御ではないため、[隔離手順](protocols/local-isolation.md)に従う。
4. 指示、許可した資料、実際に参照された資料、ツール操作、修正前後のテスト結果を記録する。情報漏えいが判明した試行を盲検成功と扱わない。
5. 成果物は実験対象から独立した評価者が確認し、観測証拠・未観測事項・評価者判断を区別して報告する。

比較条件や実験環境を固定できない場合は差異とその影響を明記し、同条件の比較と誤認させない。エージェントのモデルが自動選択などで特定できない場合は「自動選択・モデル名不明」と記録する。

## ローカル資料の配置

非公開資料の標準保存先はリポジトリ直下の`.local-data/cli-agents/`とする。保存候補と必須のアクセス制限は[ローカル隔離手順](protocols/local-isolation.md)を参照する。秘密資料は公開ブランチ、Git履歴、Issue/PR、CI artifactへ追加しない。
