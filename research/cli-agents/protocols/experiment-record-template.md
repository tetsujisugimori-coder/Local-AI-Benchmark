# 実験記録テンプレート

複製して1試行ごとに記入する。確認できない値は推測せず「未取得」または「未検証」とし、N/O・N/Aは[評価規約](evaluation.md)に従う。ログや添付には秘密資料、認証情報、個人情報を含めない。

## 識別情報

- 実験ID:
- 課題ID:
- 課題版:
- 実験日時（タイムゾーンを含む）:
- 実験者:
- エージェント名（Copilot CLI / Codex CLI / その他）:
- CLI名・バージョン:
- モデル名・バージョン: （取得できない場合は「自動選択・モデル名不明」等）

## 対象と同一性

- 対象リポジトリ（URLまたは識別子）:
- 基準SHA:
- 作業開始時の各作業ディレクトリのHEAD:
- ソース同一性の確認方法・結果（両エージェント間を含む）:
- 開始時の作業ツリー状態:
- 作業ディレクトリ識別子（秘密パスを公開記録に書かない）:

## 環境・条件

- OS・バージョン:
- CPU/メモリ等、結果に影響する環境:
- Node.js・npm等:
- ブラウザ・バージョン（該当する場合）:
- 関連ツール・依存関係のバージョン:
- ネットワーク/ツール許可と制約:
- 制限時間・操作条件:
- 条件差および比較への影響:

## 指示・資料

- 共通で与えた指示（正確な本文または公開資料への参照）:
- 追加指示・対話（時刻順。全件または改変のないログ参照）:
- 参照を許可した資料:
- 実際に参照した資料と確認方法:
- 情報汚染の有無: `なし / あり / 不明`
- 汚染がある・不明の場合の内容、判明時点、盲検性への影響:

## テスト・操作

- 修正前のテストコマンド、環境、終了コード、結果:
- 修正後のテストコマンド、環境、終了コード、結果:
- テスト結果の保存場所（公開可能な参照のみ）:
- 所要時間（開始・終了・計測方法）:
- 操作記録（時刻、操作、結果、ログ参照）:
- 最終差分の識別情報（コミットSHAまたは差分ハッシュ等）:
- push/外部送信の有無と確認結果:
