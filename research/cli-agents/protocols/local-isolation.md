# ローカル隔離と公開前確認

## 保存先とデータ区分

非公開の正解パッチ、採点用テスト、未公開課題、非公開の作業ログは、リポジトリ直下の`.local-data/cli-agents/`を標準の保管場所とする。例:

```text
.local-data/cli-agents/
  answer-key/       # 正解・参考パッチ
  hidden-tests/     # 非公開の採点テスト
  unreleased-cases/ # 未公開課題・問題文
  logs/             # 非公開の生ログ
```

この文書は保存場所の設計だけを定める。実験に伴う秘密資料や実測ログを今回作成・配置しない。

## アクセス境界

- `.gitignore`は誤追跡を防ぐ補助策であり、秘密保持やアクセス制御ではない。CLIエージェントは同じOSアカウントから読めるファイルや、許可されたツール・ネットワーク経由で資料へ到達する可能性がある。
- 正解資料・隠しテストはエージェントの作業ディレクトリ、親ディレクトリ、開いたIDE/CLIのワークスペース、エージェントに渡すプロンプトや添付へ置かない。特に秘密ディレクトリを含むリポジトリルートからエージェントを起動しない。
- 強い盲検性が必要な場合は、秘密資料を評価者専用の別OSアカウントまたはアクセス制御された別環境に置き、実験者・エージェントのアカウントから読み取りできないことを確認する。単一アカウントで同じディスクに置く場合は完全な隔離とみなさない。
- 評価者用の採点環境とエージェント用環境を分離する。隠しテストをエージェントのテストコマンドや出力から発見できる形で置かない。
- CLIごとに独立した作業ディレクトリを基準SHAから作る。作業ディレクトリ間でファイル、差分、履歴、ログ、指示への応答を共有しない。
- 認証情報、秘密資料へのアクセス権、実験対象リモートへのpush権をエージェントへ与えない。外部送信を許可しない実験では、ネットワーク・ツール権限も実行前に制限し、ログから確認する。自動アップロード機能を有効にしない。

OSアカウント、コンテナ、CLIの実際の権限境界を検証できない場合は、その制約を記録し、厳密な盲検実験として主張しない。

## 実施前チェック

1. 正解資料・隠しテストをアクセス制限された評価者専用領域に保存し、エージェント用ワークスペースおよび許可資料から到達できないことを確認する。
2. 課題、問題文、基準SHA、許可資料、評価条件を固定する。基準SHAとソース同一性を各作業ディレクトリで照合し、初期状態が一致することを記録する。
3. エージェントごとに別の作業ディレクトリを用意し、相手の成果物を参照できないこと、実験対象リポジトリへpushできないことを確認する。
4. CLIのファイル・ネットワーク・ツール権限を確認し、秘密資料、認証情報、不要なリモート書き込み権限がない状態で開始する。
5. エージェントに見えるファイル範囲、実際に読まれた資料を記録する手段と、漏えい発生時の停止・記録手順を決める。

## 公開前の漏えい確認

秘密資料を追加・更新した後、コミット、push、PR作成、artifact公開のそれぞれの前に確認する。次のチェックだけでGit履歴やGitHub上の漏えいが完全に否定できるわけではない。

```powershell
git check-ignore -v .local-data/cli-agents/answer-key/example.patch
git status --short --ignored
git ls-files -- .local-data/cli-agents/
git diff --check
git diff --cached --check
git log --all --oneline -- .local-data/cli-agents/
```

- `git check-ignore`で秘密資料の実パスが無視対象であることを確認する。
- `git ls-files`に秘密資料が出力されないことを確認する。既に追跡された資料はignoreでは除外されないため、公開を止め、履歴・ブランチ・remoteを含む対応を行う。
- status、差分、コミット対象、ブランチ履歴、PR差分に秘密の内容・ファイル名・メタデータがないことを確認する。`git log --all`はローカル履歴の確認にすぎず、remote履歴確認の代替ではない。
- `.github/workflows/`、CI設定、成果物の対象パスを確認し、秘密ディレクトリをartifactやログへ含めない。公開PRとGitHub上の差分・artifactを別途目視確認する。
- 指示文、シェル出力、スクリーンショット、操作ログにも秘密が含まれないことを確認する。秘密値をコマンド引数や共有ログへ出さない。
- 誤って公開した可能性があれば、盲検性を失ったものとして記録し、公開を停止して管理者と対応する。単にファイルを削除したりignoreへ追加したりして、履歴から消えたと判断しない。

## 今回の状態

この第0段階では正解パッチ、隠しテスト、未公開課題、作業ログを作成・保存しない。Calculator Memo事例には指定された概要と外部リンクのみを記載し、元リポジトリの資料を複製しない。
