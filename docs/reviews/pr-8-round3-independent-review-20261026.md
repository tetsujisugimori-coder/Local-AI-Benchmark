## 追加の確認事項

### P3：公開URLのクエリ値に埋め込まれた内部URL

該当箇所：[`extractHttpUrls()` と `inspectPublicContent()`](https://github.com/tetsujisugimori-coder/Local-AI-Benchmark/blob/d2b6541/src/lib/public-benchmark.ts#L1728-L1814)

検出上の限界が一つ残る。例えば次のURL。

```text
https://www.iana.org/?next=http%3A%2F%2F127.0.0.1%2Fadmin
```

外側のホストは公開ドメインだが、`next`パラメータ内には内部URLが入っている。現行の抽出・判定処理を単独で再現したところ、この内部URLは検査対象として取り出されず、ブロック条件に該当しなかった。

ただし、公開URLには警告と人間の承認が要求される。完全なURL安全性検査を保証しないことも仕様書に記載されているため、**今回はP3の残存リスクとして記録し、マージ阻止事項にはしない**。
